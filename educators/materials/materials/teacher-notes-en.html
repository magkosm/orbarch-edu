Key messages

  • Today's ISS is still messy, loud, cramped — design must improve with evidence.
  • Scientists measure, compare conditions, account for learning & confounders.
  • Blueprint trade-offs: crew mind vs. mission science/engineering.

Closing slide (after exit ticket)

  • Space is for everyone.
  • Architecture is about people.
  • Design is a series of trade-offs.
  • You are the future of space exploration.

Pilot learnings pilot: 60 students, 3 groups of ~20

  • Phones mostly OK — try Chrome if Safari glitches.
  • MATB: demo on projector first; pair if needed; mixed scores normal.
  • Blueprint addictive — repeat entrance corridor rule; give a 2-minute warning. See workshop-feedback.md.

Expected values (so you can spot a broken phone)

  • Reaction Time: 8 red dots, no time limit (~1 min). Read Average Reaction Time. Typical 200–400 ms on a phone; under ~150 ms = tapped too early.
  • MATB 2-min: Final Score = Health summed every second; max 12,000. Near-perfect ≈ 11,000+; a struggling first run can be 5,000–8,000. A 5 % drop is e.g. 10,000 → 9,500.
  • Condition Lab: % change = (② − ①) ÷ ①. Swings of ±10 % are normal for one run each; the class tally is the real result.
  • Simulator: default sliders → Overall ≈ 61; Noise to 100 → ≈ 40; everything worst → 0; everything best → 100.
  • Blueprint: starting scenario = 45. Checklist items alone = 50. Keep 1 life support + 1 science rack + bike, add 2 stowage, sleeping quarters, 2 acoustic zones, plant wall, circadian light, med bay, greenhouse → 70. Realistic ceiling ≈ 80; stretch goal ≥ 78.

Troubleshooting

  • Running long? Cut Model Lab → A3 sketch → shorten history.
  • Too many QRs? One on screen at a time only.
  • No room speakers? Use the in-app cabin noise in the Condition Lab on each phone (earphones), at the default volume.
  • No radio voice? Phone muted (iPhone side switch) or volume down. Still nothing → Chrome.
  • "New High Score" box asks for a name? Tap Skip — it appears on every fresh phone. Never type real names; nothing is uploaded, but keep it clean.
  • Which number is the score? Final Score at the top of the Simulation Complete screen (max 12,000 = Health 100 for 120 s).
  • Wrong language? ?lng=sv or ?lng=el
